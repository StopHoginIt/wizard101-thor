- **W101 Panel 0.19**: the battle card helper is switched off. In real fights it couldn't keep up with enchanting or picking spells with little time left, so battles now keep the usual shortcut tiles. The panel still notices battles: the top bar shows your pips, and the left stick still won't right-click (and discard a card) during a fight, even while the panel is folded away with ▲ Hide.
- It also does a little less work per screen snapshot, which leaves a bit more CPU for the game.

Install: open this release on the Thor and install W101Panel.apk over the old one (or run `Install-Panel.cmd` on the laptop with the Thor plugged in). Then open W101 Panel and tap Start now.
