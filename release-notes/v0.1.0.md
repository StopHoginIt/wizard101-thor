First release.

- **W101Quick-arm64.exe** — quick launcher 1.5: saved login, patch check, launches the game. Use the arm64 build on the Thor; the amd64 build hangs under FEX.
- **Wizard101-Thor-v6.icp** — GameNative controller profile: left stick = W/A/S/D (eight-way, deadzone 0.3), right stick = mouse. Use the X11 display server, not Gamescope (Gamescope leaves keys stuck).
- **W101-Companion.html** — controls cheat sheet.
- **laptop-tools.zip** — Windows adb helper scripts.

Setup: see `docs/SETUP.md`. This repo stores no credentials or personal data; the launcher keeps your login only on your own device.
