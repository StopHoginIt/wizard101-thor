Turning works right after a battle, and a faster FEX setup.

- **W101 Panel 0.18**: battle mode ends as soon as the world HUD's spellbook button is back (about 2 s), so the left stick can turn right after a fight instead of up to 40 s later. The screen capture now always matches the top screen's shape; before, it could be letterboxed, which also threw off the health, pip and spellbook readers.
- **W101Quick 2.4**: new `w101 explore` panel command (battle over), and the launcher log notes when a battle starts and ends.
- **Smoother play (settings, not files)**: in the Wizard101 container set Emulation → FEXCore Version **2611-gn-6** and add the environment variable `FEX_DISKCACHE` = `1`. FEX then keeps translated game code between launches, so areas and spells you've seen stutter less. If a launch ever hangs on a black screen, set `FEX_DISKCACHE` to `0`. Details in docs/FINDINGS.md.
