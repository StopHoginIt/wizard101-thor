Analog movement.

- **Controller profile v7** + **W101Quick 2.2**: the left stick is passed into Wine as an analog stick and the launcher turns it into movement. Up/down walk forward/back; left/right turn smoothly at a speed that follows how far you push (no more waiting for the stick to reach the "diagonal" before turning). Turn speed 3.5 by default; change it in `stick.txt` next to W101Quick.exe (`speed 3`). Turning pauses during battles (needs W101 Panel) so the stick never right-clicks a card.
- **W101 Panel 0.14**: tells the launcher when a battle is on.
- Import `Wizard101-Thor-v7.icp` in GameNative (Quick menu → Controller → Control Profiles → Import → Add to library → Apply). Profile v6 still works with the old key-based movement.
