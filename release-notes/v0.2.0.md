Faster startup and fewer stutters.

- **W101Quick 1.6**: before starting the game, the launcher creates an empty placeholder for `Data\GameData\Locale_en-US-Root.wad`. The game looks for that file tens of thousands of times per session; on Android each miss made Wine search ~2,900 game files on the game's main thread. On the AYN Thor, Play → character select went from about 2 min 50 s to about 1 min 30 s, and play has noticeably fewer stutters. It never changes KingsIsle's files; put `no-stubs.txt` next to `W101Quick.exe` to remove the placeholder.
- **Bottom screen**: GameNative's *External Display Input → Hybrid* turns the Thor's bottom screen into a touchpad with a keyboard button (works well for chat). See `docs/FINDINGS.md`.
- Docs: how to trace Wine file lookups, and measurements (the game is CPU-bound under FEX; FEX *Performance* preset is stable but made no noticeable difference).

Use **W101Quick-arm64.exe** on the Thor (copy it to `/sdcard/Download/W101Quick/W101Quick.exe`).
